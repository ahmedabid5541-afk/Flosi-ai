# فلوسي AI — Flosi AI

**صاحب المشروع ومقدّمه:** أحمد طه — جامعة قطر، تخصص المالية.

نموذج أولي تعليمي لإدارة المصروفات، يعمل محلياً أو عبر Replit باستخدام Python وStreamlit. البيانات افتراضية، والعملة الريال القطري.

## التشغيل على Replit
1. أنشئ مشروع Python جديداً في Replit.
2. ارفع ملفات هذا المجلد إلى المشروع (بما فيها ملفات CSV).
3. من Shell شغّل: `pip install -r requirements.txt`
4. شغّل: `streamlit run app.py --server.address 0.0.0.0 --server.port 8501`
5. افتح المعاينة على المنفذ 8501. قد تختلف خطوات واجهة Replit بحسب إصدارها وخطتك.

## الوظائف
- تسجيل دخل ومصروفات وإدراجها في جدول قابل للتصدير
- لوحة مالية ورسوم بيانية للفئات
- مقارنة المصروفات بالميزانية
- خطة ادخار شهرية
- مساعد إرشادي **قائم على القواعد**؛ ليس متصلاً بنموذج لغوي أو API

## حدود النموذج
- البيانات محفوظة في جلسة التطبيق؛ التغييرات لا تستمر بالضرورة بعد إغلاق الجلسة، ويمكن تصديرها CSV.
- لا يوجد تسجيل دخول أو اتصال بنكي أو توصيات استثمارية.
- لا تدّعِ أن المساعد يستخدم ChatGPT مباشرة؛ النسخة الحالية قواعد حسابية وإرشادية فقط.

## البيانات والتنظيف
`Flosi_AI_Dirty_Data.csv` يحتوي على 31 صفاً وأخطاء مقصودة: قيم ناقصة في المبلغ والفئة، تاريخ بصيغة مختلفة، تسمية نوع عملية غير موحدة، مسافة زائدة في الفئة، وصف مكرر. `Flosi_AI_Clean_Data.csv` يحتوي على 30 صفاً من البيانات الأصلية المرجعية. تم إنتاج النسخة النظيفة بالرجوع إلى البيانات الأصلية، وليس بإصلاح آلي يستنتج القيم الناقصة. لا تنسب تصحيحات يدوية أو تجارب شخصية لمن لم يقم بها.

## الاختبارات
`python -m pytest -q` لاختبار الحسابات والتحقق من الإدخال. اختبارات الواجهة على Replit تحتاج تجربة يدوية لاحقاً.
